\# Hand Tracking



Real-time hand tracking and landmark detection

using Python, OpenCV, and MediaPipe.



\## Files



\- HandTrackingMin.py - Basic hand tracking

\- HandTrackingModule.py - Reusable hand detector class

\- HandTrackingGame.py - Hand tracking application



\## Features



\- Real-time hand detection

\- Hand landmark visualization

\- Extraction of 21 hand landmark positions

\- FPS calculation



\## Running



Install dependencies:



pip install -r requirements.txt



Run the module:



python HandTrackingModule.py
